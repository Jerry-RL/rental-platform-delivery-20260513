# 租车平台 · 方案预览版（Preview）

面向客户方案演示的**纯前端**预览工程，包含 **管理后台** 与 **H5 用户端**，无需启动真实后端服务。  
接口路径、请求/响应字段与 `docs/03-API/OpenAPI/openapi-gateway-rental-v1.yaml` 及 SRS v1.9 模块对齐，数据由内置 Mock API 提供。

**文档对齐**：见 [`docs/Preview功能与正式文档对照.md`](./docs/Preview功能与正式文档对照.md) 与交付包 [`docs/preview方案演示对齐说明.md`](../docs/preview方案演示对齐说明.md)。

## 快速启动

```bash
cd preview
npm install
npm run dev:admin   # 管理端 http://localhost:5173
npm run dev:h5      # H5     http://localhost:5174
```

生产构建：`npm run build`

## 推荐演示路径（15 分钟）

1. **H5** 首页「按车款选」→ 自驾下单  
2. **H5** 切换「包车带司机」→ 无需驾照，显示指派司机  
3. **H5** `13600136097` 自驾 → **管理端** 用户与认证 → 驾照通过 → 再下单  
4. **管理端** 订单详情 → 用户 / 车辆历史 / 司机链接  
5. **管理端** 退款「已退款」或发票「已开具」→ 订单状态同步  

## 管理端要点

- **黑色主题**、分组折叠侧栏  
- 订单：履约 + **财务状态**（开票/退款）、服务方式列  
- 支付退款 / 电子发票：操作后 **自动同步订单**（`order-status.ts`）  
- 车辆管理：Tab（库存/生命周期/里程/违章/维保）  
- 企业：客户 / 成员 / 开通审批  

## Mock API

- 客户端：`@rental-preview/shared` → `handleMockRequest`  
- 响应：`{ code, message, data, timestamp, requestId }`  
- 管理端 CRUD：`/api/v1/admin/{resource}` + batch-delete / batch-update
