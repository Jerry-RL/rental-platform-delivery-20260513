# Preview · 司机管理（历史订单与违章）

版本：1.0  
日期：2026-06-01  
对齐：FR-OPS-008、FR-ORD-007

---

## 1. 能力说明

| 能力 | 说明 |
|---|---|
| 司机档案 CRUD | 管理端「司机与人员」· 包车司机工号、城市、在岗状态 |
| 司机详情档案 | `/staff/drivers/:id` · 历史包车订单、违章归因、服务统计 |
| C 端司机预览 | H5 `/drivers/:id` · 下单前查看评分、驾龄、平台单量/违章摘要 |
| 订单关联 | 订单详情「司机」链接跳转司机档案 |

---

## 2. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/admin/drivers` | 分页列表 |
| GET | `/api/v1/admin/drivers/:id/profile` | 管理端完整档案（订单+违章+统计） |
| GET | `/api/v1/drivers/:id` | C 端司机详情（含 `recentOrderCount`、`violationCount`） |

实现：`packages/shared/src/driver-admin-profile.ts`

---

## 3. 违章归因规则（演示）

1. **明确归属**：违章记录带 `driverId` 时直接计入该司机。  
2. **租期内推断**：无 `driverId` 时，若违章时间在「该司机包车订单」的 `pickupTime`～`returnTime` 且同 `vehicleId`，则关联展示并标注「租期内推断」。

车队级批量查询仍在 **车辆管理 → 违章查询**。

1. 管理端 → **司机与人员** → 点击「历史/违章」
