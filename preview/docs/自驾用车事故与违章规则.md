## 1. 适用场景

| 服务方式 | 事故上报（租期中） | 违章责任 |
|---|---|---|
| **SELF_DRIVE 自驾** | 用车人上报 · 承租人责任 | 承租人 `RENTER` |
| **WITH_DRIVER 包车** | 用车人可上报 · 平台协调 | 平台司机 `PLATFORM_DRIVER` |
| **B/G 企业自驾** | 成员上报 · 企业账单 | `ENTERPRISE` |
| **MIXED** | 同自驾（演示简化） | 承租人 `RENTER` |

自驾须：**实名 + 驾照** 通过；事故与违章均须 **关联使用中/租期内订单**。

## 2. 租期事故规则（FR-ORD-008 ~ 012）

### 2.1 上报门禁

- 仅订单状态 **`IN_USE`（使用中）** 可创建事故单（错误码演示 **3010**）。
- 仅 **订单用车人** `userId` 可上报。

### 2.2 责任与场景

与违章共用 `responsibleParty` / `serviceContext` 枚举（`incident-rules.ts`）。

### 2.3 上报后联动（Preview）

| 动作 | 说明 |
|---|---|
| `incidentPending=true` | 订单标记待结事故（BR-031） |
| `pauseBilling` | 默认申请暂停计费（FR-ORD-010） |
| `vehicleHold` | 默认车辆 `ACCIDENT_HOLD`（BR-030） |
| 客服工单 | 自动创建，人伤为高优先级（BR-033） |

### 2.4 状态机

`REPORTED` → `UNDER_REVIEW` → `INSURANCE_PROCESSING` → `RESOLVED` / `CLOSED`

### 2.5 API

| 方法 | 路径 |
|---|---|
| GET | `/api/v1/orders/:id/incident-gate` |
| POST | `/api/v1/orders/:id/incidents` |
| GET | `/api/v1/users/me/incidents` |
| GET | `/api/v1/users/me/incidents/summary` |
| GET | `/api/v1/incidents/:id`（C 端详情，仅本人可见订单事故） |
| GET | `/api/v1/admin/incidents` |
| GET | `/api/v1/admin/incidents/:id`（管理端详情） |

**Preview 路由**：H5 `/incidents/:id`；管理端 `/incidents/:incidentId`。列表与订单详情均提供「查看详情」入口。

实现：`packages/shared/src/incident-rules.ts`（`getIncidentById`）

## 3. 交通违章规则（摘要）

详见 [用户驾车违章规则](./用户驾车违章规则.md)。

- 数脉批量查询 → 按 **车牌 + 违章时间 ∈ 租期** 匹配订单  
- 对客：`罚款 + 代办费（50 元）` → 押金/账单扣除  
- H5：**我的违章** `/violations`

实现：`packages/shared/src/violation-attribution.ts`

## 7. 演示脚本（15 分钟）

1. C 端 `13800138000` 登录 → **订单** 打开使用中订单 `ORD20260515002` → **上报租期事故**（或查看已有事故）  
2. **我的 → 我的事故** / **我的违章**  
3. 管理端 **事故处理**、**违章查询**、**订单详情** 核对归因  
4. 车辆 `沪B98765` 状态为 **事故停运**（ACCIDENT_HOLD）
