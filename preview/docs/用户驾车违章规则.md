## 1. 业务目标

| 目标 | 说明 |
|---|---|
| 责任清晰 | 自驾 / 包车 / 企业下单场景下，明确谁承担违章 |
| 订单关联 | 违章时间与车牌匹配租期订单，可追溯到承租人 |
| 对客透明 | H5 展示「我的违章」、订单详情展示关联记录 |
| 运营闭环 | 管理端批量查询 → 自动归因 → 处理/入账/追缴 |

## 2. 责任认定规则（BR-VIO）

| 条件 | 责任主体 `responsibleParty` | 说明 |
|---|---|---|
| 违章时间在订单租期内，且 `serviceMode=SELF_DRIVE` | `RENTER` 承租人 | 下单用户承担罚款+代办费 |
| 租期内 `WITH_DRIVER` | `PLATFORM_DRIVER` 平台司机 | 平台先行处理；`driverId` 回填指派司机 |
| 租期内 B/G 后付/企业账单 | `ENTERPRISE` 企业客户 | 记入企业账单主体，成员可见 |
| 租期内 `MIXED` | 按订单主 `serviceMode` 演示归为 `RENTER` | 正式版可按时段拆分 |
| 无匹配订单 | `UNKNOWN` | 非租期，运营人工认定 |

**匹配算法（Preview）**

```
matchOrder(vehicleId, violationTime):
  orders where vehicleId相同
    AND pickupTime <= violationTime <= returnTime
  取 pickupTime 最近的一条
```

实现：`packages/shared/src/violation-attribution.ts` → `attributeViolationRecord()`

## 3. 费用与结算

| 字段 | 说明 |
|---|---|
| `fineAmount` | 交管罚款金额 |
| `serviceFee` | 平台代办服务费（Preview 默认 **50 元**，承租人/企业承担时计入） |
| `totalDue` | `fineAmount + serviceFee`（展示用） |
| `status` | 缴款：`UNPAID` / `PAID` |
| `liabilityStatus` | 追责：`PENDING` → `CONFIRMED` → `BILLED` → `SETTLED` / `WAIVED` |

结算渠道（协议约定，Preview 文案演示）：

1. 优先从 **押金** 扣除  
2. 不足部分计入 **订单附加费** 或 **企业月结账单**  
3. 已缴款且处理完成 → `liabilityStatus=SETTLED`

## 8. 与正式实现的差异（Preview 简化）

- 不做违章申诉工单流（正式 Out of Scope 一期）  
- 不实际扣款，仅状态与金额展示  
- 混合租期不按时段拆分责任  
- 数脉 API 为 Mock 随机命中，字段形态对齐正式设计
