# Preview · 服务类型与下单规则

对照 SRS **服务方式（serviceMode）** 与 **FR-USER-014 用车资格**，Preview 支持三种 **服务类型**。

## 服务类型枚举

| 值 | 中文 | 适用场景 | 客户驾照 | 实名 |
|---|---|---|:---:|:---:|
| `SELF_DRIVE` | 自驾 | 客户本人驾驶 | **必须** | 必须 |
| `WITH_DRIVER` | 包车带司机 | 全程平台司机 | **不需要** | 必须 |
| `MIXED` | 部分带司机+自驾 | 分时段司机+自驾，或租车篮内多车混选 | **必须**（含自驾段） | 必须 |

规则源码：`packages/shared/src/service-mode.ts` → `SERVICE_MODE_META`

### 与租车篮的关系

| 层级 | 可选值 | 说明 |
|---|---|---|
| **每台车**（首页/篮内） | 仅 `SELF_DRIVE` / `WITH_DRIVER` | 单车不能同时为混合 |
| **订单/下单页** | 三种均可 | 篮内同时有自驾+包车 → 结算展示为「部分带司机+自驾」，分单下单 |
| **单台下单页** | 选 `MIXED` | 演示按约 45% 司机服务费 + 须驾照 |

## 资格校验

```
GET /api/v1/users/{userId}/eligibility?serviceMode=SELF_DRIVE|WITH_DRIVER|MIXED

POST /api/v1/orders/quote   → 自驾/混合不通过则拒绝
POST /api/v1/orders         → 同上
```

| serviceMode | 校验项 |
|---|---|
| SELF_DRIVE | 黑名单/冻结、实名、驾照 |
| WITH_DRIVER | 黑名单/冻结、实名 |
| MIXED | 同自驾（含自驾段须驾照） |

## 计价（Preview）

| 类型 | 司机费 |
|---|---|
| WITH_DRIVER | 全额司机服务费 |
| MIXED | 约 45% 全额（演示「部分时段」） |
| SELF_DRIVE | 无 |

## H5 交互

- **单台下单**：三选一服务类型卡片
- **租车篮**：每台车自驾/包车；篮内两种皆有 → 底部与结算页标「部分带司机+自驾」
- **多台自驾**：每台车登记一名「本次自驾司机」并上传**该司机**驾照（`SELF_DRIVE_DRIVER`）；结算页 `CartSelfDriveLicensePanel`
- **单台自驾**：可用账户「本人驾照」（`ACCOUNT_HOLDER`）或按车登记司机驾照
- **全部包司机**：仅改篮内单车类型，不设 MIXED 枚举存车项
