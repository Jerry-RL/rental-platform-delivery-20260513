# Preview · 报废提醒与里程监控

扩展 **FR-VEH-006** 车辆运营成本管理：在管理端对车队进行**报废阈值提醒**与**里程异常监控**。

## 1. 报废提醒

| 维度 | 默认阈值 | 单车字段 |
|------|----------|----------|
| 里程 | 120,000 km | `scrapMileageLimitKm` |
| 车龄 | 8 年 | `maxServiceYears` + `purchaseDate` |

| 级别 | 条件 |
|------|------|
| `OK` | 未触发 |
| `DUE_SOON` | 剩余里程 ≤12,000 km **或** 剩余服役 ≤1 年 |
| `OVERDUE` | 里程/车龄已达上限 |
| `RETIRED` | 车辆状态已为报废 |

## 2. 里程监控

基于 `mileage_records` 最近流水计算：

| 级别 | 条件 |
|------|------|
| `NORMAL` | 无告警 |
| `ANOMALY` | 最近一次录入增量 ≥1,500 km |
| `HIGH_USAGE` | 近程日均 ≥350 km |
| `STALE` | 超过 45 天无里程同步（还车/GPS/人工） |

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/vehicles` | 列表含 `scrapLevel`、`mileageMonitorLevel` 等扩展字段；支持筛选 `scrapLevel`、`mileageMonitorLevel` |
| GET | `/api/v1/admin/scrap-reminders` | 待处理报废提醒（非 OK） |
| GET | `/api/v1/admin/mileage-monitor` | 非 NORMAL 的里程监控项 |
| GET | `/api/v1/admin/fleet-monitor/summary` | `{ scrapDue, mileageAlert, maintDue }` |

## 4. 管理端 UI

- **车辆库存**：列「保养 / 报废提醒 / 里程监控」+ 筛选项
- **里程·报废监控** Tab：汇总卡片 + 报废表 + 监控表 + 保养表 + 里程流水
