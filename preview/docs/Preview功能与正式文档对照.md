## 3. 订单状态（Preview 扩展）

正式 SRS 履约状态 + Preview 增加的 **财务延伸状态**（可由发票/退款单据驱动，见 `packages/shared/src/order-status.ts`）：

| 状态码 | 中文 | 类型 |
|---|---|---|
| PENDING_PAYMENT … COMPLETED | 见 `orderStatusLabel` | 履约 |
| CANCELED / PAYMENT_FAILED | 取消/支付失败 | 异常 |
| INVOICE_PENDING / INVOICE_ISSUED | 开票中/已开发票 | 财务 |
| REFUND_PENDING / REFUND_PARTIAL / REFUND_SUCCESS | 退款相关 | 财务 |

管理端：订单列表筛选全部状态；退款「已退款」、发票「已开具」会触发订单状态同步。

## 5. 推荐演示脚本（30 分钟）

1. **H5** 登录 `13800138000` → 首页按车款选 SUV → 自驾下单（资格已通过）  
2. **H5** 切换 `13900139000` → 包车带司机下单（无驾照要求）  
3. **H5** 登录 `13600136097` → 自驾被拦 → `/license` 上传 → **管理端** 驾照审核通过 → 再下单  
4. **管理端** 订单详情 → 点击用户/车辆历史/司机链接  
5. **管理端** 退款单改为「已退款」→ 订单变「退款成功」  
6. **管理端** 发票批量已开 → 订单变「已开发票」

## 6. 与 OpenAPI 的差异（Preview 已知）

- 无真实 JWT/OCR/支付/诺诺百望开票，均为 Mock  
- 部分管理端写接口路径为 `/api/v1/admin/{resource}`，与网关合并版子路径等价演示  
- `GET /api/v1/drivers` 为 Preview 补充，便于 H5 展示指派司机  

正式开发请以 `docs/03-API/OpenAPI/openapi-gateway-rental-v1.yaml` 为准，Preview 仅作交互与字段形态参考。
