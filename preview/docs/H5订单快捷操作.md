# Preview · H5 订单快捷操作与再次下单

## 能力概览

| 场景 | 快捷操作 |
|---|---|
| 首页 | 选车 / 订单 / 驾照 / 实名 / 租车篮结算；**再次下单**横向卡片（最近可复购订单） |
| 订单列表 | 状态筛选；卡片底栏含 **确认租车服务开始**（列表紧凑文案「确认服务开始」） |
| 订单详情 | 待开始服务时底部固定主按钮 **确认租车服务开始**；其余状态为快捷操作栏 |
| 我的 | 「再次下单」列表，一键跳转下单页 |

规则源码：`packages/shared/src/order-actions.ts`、`order-fulfillment.ts`（`PUT …/pickup`）

## 再次下单

1. 拉取原单车辆 `GET /api/v1/vehicles/{vehicleId}`
2. 生成 query：`city`、`vehicleId`、`vehicleTypeId`、`brand`、`model`、`serviceMode`、`settlementMode`、`pickupStoreId`、`returnStoreId`、`pickupTime`、`returnTime`、`reorder=1`
3. 跳转 `/booking?…`，下单页预填服务方式、**交车/还车时间与门店**，并提示「已根据上一单预填…」

可再次下单状态：`COMPLETED`、`SETTLED`、`INVOICE_*`、`REFUND_SUCCESS`、`REFUND_PARTIAL`、`CANCELED`
