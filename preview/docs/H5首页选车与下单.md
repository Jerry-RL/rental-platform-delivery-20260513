# Preview · H5 首页选车与下单

对照 SRS **选车下单** 与 OpenAPI 创建订单（`vehicleTypeId` / `vehicleId`），Preview H5 支持首页 **多型号（车款）** 选择后进入下单页。

## 首页能力

| 模式 | 说明 |
|---|---|
| 按车款选 | 按 `vehicleTypeId + brand + model` 聚合；**勾选**加入租车篮（默认取该款首台可租） |
| 按车辆选 | 按单车牌列表；**多选勾选**（默认视图），支持「全选本页」 |
| 按车服务方式 | 每台车可单独选 **自驾 / 包车**；工具栏 **全部包司机** / **全部自驾** |
| 租车篮 | 底部栏可展开/移除车辆；未同意协议时「去结算」先弹必读 sheet；最多 20 台；按每台 `serviceMode` 试算下单 |
| 城市 | 暂不按城市筛选首页列表；车辆卡片展示所属城市，下单页按车选门店 |
| 车型筛选 | 经济/轿车/SUV/MPV/新能源/豪华 |

聚合逻辑：`packages/shared/src/vehicle-catalog.ts`

## 车辆图片（可展示）

模拟/爬取外链（如 Unsplash）在演示环境常无法加载。Preview 统一经 `packages/shared/src/vehicle-images.ts`：

- 种子车队 200+ 台使用 **内置 SVG Data URL**（离线可展示）
- `GET /api/v1/vehicles` 返回前自动 `resolveVehicleImageUrl`
- 管理端上传仍为 `data:image/...`，原样保留
- H5/管理端 `VehicleImage` 组件加载失败时二次回退

- `buildVehicleModelOfferings()` — 车款卡片  
- `buildVehicleTypeSummaries()` — 顶部车型快捷条  

## 租车篮（localStorage）

- 存储键：`rental-preview-h5-vehicle-cart`
- 逻辑：`packages/shared/src/vehicle-cart.ts`（`VehicleCartItem.serviceMode`）
- H5：`VehicleCartBar` · `useVehicleCart` · `VehicleServiceModeChips`

## 跳转下单参数

单台：

```
/booking?city=上海&vehicleTypeId=SUV&brand=丰田&model=RAV4&vehicleId={uuid}
```

租车篮批量：

```
/booking?cart=1&city=上海
```

结算页按篮内车辆逐台试算、逐台 `POST /api/v1/orders`（每台携带各自 `serviceMode`；包车单带 `driverId`）。

下单页：

- 顶部 **「预定交车时间与地点」**（`HandoverScheduleSection`）：交车时间、还车时间、交车门店（地址/电话）、同店还车/异店还车  
- 交车时间快捷：明日 09:00 / 14:00、约 2 小时后、3 天后 10:00；还车时间相对交车 +1/+3/+7/+30 天  
- 交车门店列表优先匹配车辆所属城市；底部提交栏展示交车时间·门店摘要  
- 加载可租车辆，同车款多台可切换车牌  
- 报价/下单使用选中 `vehicle.id`  
- 无 `vehicleId` 时按车型+品牌+车款自动匹配（`pickVehicleForBooking`）

再次下单 URL 可带 `pickupTime`、`returnTime`（`datetime-local` 格式），与 `pickupStoreId` / `returnStoreId` 一并预填。

## 车辆 / 司机详情

| 路由 | 说明 |
|---|---|
| `/vehicles/:id` | 车辆详情：图集、状态、里程、门店、证件、近期动态；可「预订此车」 |
| `/drivers/:id` | 司机详情：评分、驾龄、服务数据、资质（包车指派预览） |

入口：首页车辆卡片「查看详情」、下单页车辆/司机区块、订单详情关联信息。

Mock：`GET /api/v1/vehicles/{id}`、`GET /api/v1/vehicles/{id}/history`、`GET /api/v1/drivers/{id}`

## 订单前必读协议

- 文案：`packages/shared/src/rental-agreements.ts`（服务协议 / 押金违章 / 隐私）
- 首页租车篮：未同意时「去结算」先弹出底部协议 sheet（贴底白底），操作按钮区 `pb-tab-bar` 避开 Tab，勾选后写入 `sessionStorage`
- 下单页：正文区展示必读摘要 + 查看全文；底部固定栏（`bar-surface` 白底、`bottom: 0`）勾选后方可提交

## Mock API

| 接口 | 说明 |
|---|---|
| GET `/api/v1/vehicles?status=AVAILABLE` | 首页、下单页拉车（暂不带 city） |
| POST `/api/v1/orders/quote` | 支持 `vehicleTypeId`+`brand`+`model`+`city` 解析车辆 |
| POST `/api/v1/orders` | 创建订单，可仅传 `vehicleTypeId` |
