# Preview · 车辆全生命周期轨迹

对照 **FR-VEH-006/007**（维保、保险）及订单履约，在管理端按**时间轴**展示单车历史。

## 事件类型

| 类型 | 来源 |
|------|------|
| PURCHASE | 采购入库（种子 + 合成） |
| MAINTENANCE | 维保工单 `orderType=ROUTINE` |
| REPAIR | 维保工单 `orderType=REPAIR` |
| INSURANCE | 投保/续保（种子 + 按到期日合成） |
| ANNUAL_REVIEW | 年检档案 |
| ORDER | 租赁订单（取车/还车节点） |

## API

`GET /api/v1/admin/vehicles/{vehicleId}/history`

响应 `VehicleHistoryTimeline`：`events[]` 按 `occurredAt` **升序**。

## 实现

- 聚合：`packages/shared/src/vehicle-history.ts` → `buildVehicleHistory()`
- 种子：`seedVehicleHistoryEvents`（演示锚点车）
- UI：管理端「车辆管理」→「车辆全生命周期轨迹」
