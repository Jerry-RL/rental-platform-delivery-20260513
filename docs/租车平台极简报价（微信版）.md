# 租车平台极简报价（微信版）

日期：2026-05-18

## 一句话方案
4~6周交付「车辆管理 + 批量违章 + GPS定位轨迹 + 到期提醒 + 小程序地图能力」，支持后续扩展。

## 报价区间（首年）

- 经济版：`10.6万 ~ 16.1万`
- 标准版：`16.2万 ~ 28.6万`
- 增强版：`27.6万 ~ 54.0万`

> 说明：以上为首年总成本（开发实施 + 服务器带宽 + 第三方服务费）。

## 本次交付内容

- 车辆管理（档案、状态、运营信息）
- 保险/年审到期提醒
- 批量违章查询（含配额与成本控制）
- GPS厂商API对接（实时定位、轨迹回放）
- 小程序地图输入与定位展示

## 周期与里程碑

- 第1~2周：需求冻结 + 基础功能开发
- 第3~4周：违章批量 + GPS定位轨迹
- 第5~6周：联调压测 + 上线交付

## 付款方式（建议）

- 40% 启动款（签约后）
- 40% 中期款（核心功能联调通过）
- 20% 尾款（上线稳定7天）

## 不含项（客户需知）

- 违章接口调用费（按调用量）
- GPS厂商平台服务费
- 地图商用授权费（如触发）
- 短信、CDN、域名、证书等云增值费用

## 可直接发客户的话术

“我们建议按首年总成本来看项目，避免后期预算失控。  
开发费是一次性投入，服务器和第三方接口是持续运营成本。  
现在可以先按标准版启动，后续根据业务增长平滑升级。”
