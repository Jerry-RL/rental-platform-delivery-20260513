## 1. 采购背景（RFP 摘要）

| 项 | 要求 |
|---|---|
| 采购方 | 租车平台运营主体（单税号，可扩展多门店） |
| 业务场景 | C 端散单 + **B/G 月结合并开票**；数电专票/普票 |
| 预估量 | **80~200 张/月**，峰值 300 张/月；年红冲率 < 5% |
| 集成方式 | REST API + **异步回调** + 红冲；对接现有 Finance Service |
| 必含能力 | 蓝票、红冲、PDF/OFD、抬头校验、备注字段、批量/合并开票 |
| 评分权重建议 | 功能 30% · 价格 25% · 集成 25% · 服务 20% |

## 8. 选型建议（本项目）

| 场景 | 倾向 |
|---|---|
| 追求 **快速上线、API 简单、中小企业案例多** | 略倾向 **诺诺** |
| 已有 **百望/ERP/钉钉发票夹**，或重视 **业财税一体** | 略倾向 **百望** |
| 200 张/月、单主体 | **两者均可**，以 **§4 首年总价 + §5 联调周期** 决胜 |

**决策流程**：收报价 → 填 §2 评分 → 20 单沙箱联调 → 合同锁定 2 年价格 → Adapter 配置 `default_provider`。
