## 2. 接口能力摘要

- **覆盖**：全国范围未处理违章详情。
- **返回字段（示例）**：违章地点、违章行为、罚款金额、记分、违章城市等。
- **入参（必填）**：车牌号、发动机号、车架号（VIN）、车辆类型（大型车/小型车/新能源等，挂车除外）。
- **合规**：企业实名用户可用；**需提供应用场景审核**（租车/汽车租赁场景说明）。

---

## 3. 平台适配层约定

### 3.1 请求映射（车辆主数据 → 供应商）

| 平台字段 | 供应商参数 | 来源 |
|---|---|---|
| plate_number | 车牌号 | `vehicle.plate_number` |
| engine_no | 发动机号 | `vehicle.engine_no`（需入库） |
| vin | 车架号 | `vehicle.vin` |
| vehicle_type_code | 车辆类型 | `vehicle.vehicle_type_code`（枚举映射） |

### 3.2 响应归一化（内部模型）

```json
{
  "provider": "SHUMAI",
  "vehicleId": "uuid",
  "queryStatus": "SUCCESS",
  "violations": [
    {
      "occurredAt": "2026-05-01T10:00:00+08:00",
      "location": "杭州市西湖区xxx路",
      "behavior": "违反禁令标志",
      "fineAmount": 200,
      "points": 3,
      "city": "杭州",
      "processed": false
    }
  ],
  "unitCost": 0.06,
  "rawRef": "provider_request_id"
}
```

### 3.3 幂等与计费

- 幂等键：`SHUMAI:{tenantId}:{vehicleId}:{queryDate}`（可选同日去重，见 BR-025）。
- **仅对供应商返回成功且计费的调用**写入 `unit_cost=0.06`；超时重试不重复计费（以供应商账单为准）。

---

## 4. 批量任务联动

- 批量任务按 **车辆数 × 单价** 预估：`estimated_cost = vehicle_count * 0.06`。
- 任务完成后：`actual_cost = success_count * unit_cost`。
- 配额默认每月 2 次（租户级），单次任务若查询 200 台车且成功，消耗 **200 次** 供应商额度 + 记 **1 次** 租户月度配额（与 SRS BR-023/024 一致，以产品配置为准）。
