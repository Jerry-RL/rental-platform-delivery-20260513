# 租车平台交付文档索引概览

版本：1.1  
日期：2026-06-01

本文档为 `docs/` 目录的总索引，按**项目管理与软件开发流程**组织，便于产品、研发、测试、商务快速定位所需资料。

---

## 推荐阅读路径

| 角色 | 建议阅读顺序 |
|---|---|
| 产品 / 业务 | 业务背景与客户痛点 → 需求规格说明书 → **订单定价策略** / **运营成本管理** → 需求补充说明书 → 扩展功能 PRD → 需求评审与设计完善 |
| 商务 / 决策 | 业务背景与客户痛点 → **订单开票方案对比** → 极简报价 → TCO |
| 架构 / 研发 | 需求规格说明书 → **技术栈选型** → 架构与详细设计说明书 → API / 数据库 / 事件契约 → 网关配置 |
| 测试 / QA | 需求规格说明书 → 验收标准与交付清单 → API 规范与错误码 |
| 项目经理 | 一期迭代排期 → 实施报价与里程碑 → 第三方接口与成本控制 |
| 商务 / 签约 | 极简报价（微信版）→ 实施报价与里程碑 → 客户签约版成本测算（TCO） |

```mermaid
flowchart LR
  A[需求规格 SRS] --> B[需求补充 / PRD]
  B --> C[需求评审]
  C --> D[架构设计 SDD]
  D --> E[API / 数据库 / 事件]
  E --> F[网关配置]
  F --> G[项目计划 / 报价]
  G --> H[验收与交付]
```
