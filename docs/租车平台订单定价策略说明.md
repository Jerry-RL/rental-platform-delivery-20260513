# 租车平台订单定价策略说明

版本：v1.0  
日期：2026-06-01  
适用对象：产品、运营、研发、测试、商务  
关联文档：[租车平台需求规格说明书.md](./租车平台需求规格说明书.md)、[租车平台架构与详细设计说明书.md](./租车平台架构与详细设计说明书.md)

---

## 1. 文档目的

定义租车订单从**下单估价**到**还车结算**的定价维度、计费模式、优惠叠加顺序与业务规则，支撑：

- 运营后台配置价格（FR-OPS-001 扩展）
- 订单费用明细落库（`order_fee_detail`、`orders.rental_fee` / `chauffeur_fee` / `surcharge_fee`）
- B/G 端 **纯租车（SELF_DRIVE）** 与 **包车带司机（WITH_DRIVER）** 分流计价（BR-016、BR-017）

---

## 2. 定价维度总览

| 维度 | 枚举/示例 | 作用阶段 | 说明 |
|---|---|---|---|
| **计费模式** | 按时间 / 按里程 / 时间+里程 | 估价 + 结算 | 决定主计价公式 |
| **时间粒度** | 小时 / 天 / 周 / 月 | 估价 + 结算 | 租期换算与超时规则 |
| **车辆类型** | 经济型、商务型、SUV、MPV、新能源、大型车 | 估价 | 匹配 `vehicle_type_id`、`vehicle_type_code` |
| **车辆数量** | 1 台 / 多台（车队批量） | 估价 | 批量折扣、库存占用按台数 |
| **服务方式** | `SELF_DRIVE` / `WITH_DRIVER` | 估价 + 结算 | 是否计司机费、是否校验驾照 |

## 3. 计费模式（Pricing Basis）

### 3.1 三种主模式

| 模式代码 | 名称 | 适用场景 | 估价公式（示意） |
|---|---|---|---|
| `TIME` | **按时间** | 短租日租、长租月租、包车按天 | `租金 = 单位时间价 × 计费时长 × 车型系数 × 门店系数` |
| `MILEAGE` | **按里程** | 按公里包车、通勤专线（少见） | `租金 = 单位里程价 × 预估里程 × 车型系数` |
| `HYBRID` | **时间 + 里程** | 行业最常见：日租含公里，超出另计 | `租金 = 时间价 + max(0, 实际里程 - 含公里) × 超公里单价` |

### 3.2 时间粒度与换算

| 时间单位 | 代码 | 最短租期 | 不足整单位 | 超时（还车晚于约定） |
|---|---|---|---|---|
| 按小时 | `HOUR` | 4 小时（可配置） | 向上取整到 1 小时 | 按小时单价 × 超时小时数 |
| 按天 | `DAY` | 1 天 | 不足 1 天按 1 天 | 按天单价 × 超时天数（或转小时规则） |
| 按周 | `WEEK` | 7 天 | 不足 1 周按 1 周 | 按周单价或折算为天 |
| 按月 | `MONTH` | 30 天（自然月可选） | 不足 1 月按 1 月 | 按月单价或按天折算 |

**租期计费时长**（用于按时间模式）：

```
planned_duration =
  IF unit == HOUR: ceil_hours(return_time - pickup_time)
  IF unit == DAY:  ceil_days(return_time - pickup_time)
  ...
```

### 3.3 里程规则（按里程 / 混合模式）

| 项 | 说明 |
|---|---|
| 起算点 | 提车验车里程 `pickup_mileage_km`（仪表盘或 GPS） |
| 止算点 | 还车验收里程 `return_mileage_km` |
| 实际里程 | `actual_km = return_mileage_km - pickup_mileage_km`（异常负值走人工） |
| 含公里数 | 规则配置 `included_km`（按天可配置「200km/天」或整单「500km」） |
| 超公里单价 | `overage_km_rate`（元/公里），按车型可不同 |
| GPS 校验 | 可选：与 GPS 轨迹里程比对，偏差 > 阈值转人工 |

```
mileage_fee = max(0, actual_km - included_km_total) * overage_km_rate
```

## 4. 车辆类型维度

与车辆主数据 `vehicle_type_id`、`vehicle_type_code` 对齐（违章对接码 `SMALL`/`LARGE`/`NEW_ENERGY` 可映射，业务展示用下表）：

| 业务车型代码 | 名称 | 典型计费系数 | 驾照要求（C 端） |
|---|---|---:|---|
| `ECONOMY` | 经济型 | 1.00 | C1 |
| `BUSINESS` | 商务型 | 1.25 | C1 |
| `SUV` | SUV | 1.30 | C1 |
| `MPV` | MPV/7座 | 1.40 | C1 |
| `NEW_ENERGY` | 新能源 | 1.05 | C1/C2 按车型 |
| `LARGE` | 大型车/中巴 | 1.80 | A1/A3 等 |

每种车型在 `price_rule` 上配置**独立基价**或**全局基价 × 系数**二选一（运营可选策略）。

## 5. 车辆数量维度（批量 / 车队）

| 场景 | 订单结构 | 定价规则 |
|---|---|---|
| 单台 | `vehicle_qty = 1`，单 `vehicle_id` | 直接匹配车型价表 |
| 多台同车型 | `vehicle_qty = N`，N 条库存占用或子订单行 | 基准价 × N，再应用**数量阶梯折扣** |
| 多台异车型 | 主订单 + 多 `order_line`（每行一个车型+数量） | 各行独立计价后汇总 |

**数量阶梯折扣示例**（可配置）：

| 车辆数 N | 折扣系数 |
|---:|---:|
| 1 | 1.00 |
| 2 ~ 5 | 0.95 |
| 6 ~ 10 | 0.90 |
| 11+ | 协议价（人工录入或合同价表） |

```
fleet_subtotal = sum(line_quote(line_i) for each line)
fleet_total = fleet_subtotal * qty_discount(N)   // 同车型批量时
```

> B/G 政务或企业车队订单常见「多台 + 包车」，需同时校验**每台车库存**与**司机数量**（见 §6.2）。

## 6. 服务方式：单独租车 vs 包司机

与订单字段 `orders.service_mode` 一致：

| 服务方式 | 代码 | 租金 | 司机费 | 里程/超时 |
|---|---|---|---|---|
| **单独租车** | `SELF_DRIVE` | 按 §3~§5 计算 | **0**（BR-017） | 客户驾驶，里程计入超公里 |
| **包车带司机** | `WITH_DRIVER` | 可按时间或混合；常含部分里程 | **另计**（BR-016） | 以订单/GPS 为准；司机工时可选 |

### 6.1 司机费计价（`WITH_DRIVER`）

| 计费项 | 代码 | 说明 |
|---|---|---|
| 基础包车费 | `CHAUFFEUR_BASE` | 含司机服务时长，可与「日租」合并展示 |
| 司机超时 | `CHAUFFEUR_OVERTIME` | 超过含服务时长，按小时单价 |
| 司机餐宿补贴 | `CHAUFFEUR_ALLOWANCE` | 跨夜、长途一次性费用（规则配置） |
| 里程费 | `CHAUFFEUR_MILEAGE` | 若司机费模式为「按里程」，与租金拆分 |

**分配前置**：进入「待提车/待出车」前须 `driver_id` 已分配且排班有效（BR-016）。

```
IF service_mode == WITH_DRIVER:
  chauffeur_fee = calcChauffeur(rule, duration, mileage, vehicle_type)
  rental_fee = calcRental(rule, ...)   // 可能为 0（全包在司机费）或拆分
ELSE:
  chauffeur_fee = 0
  rental_fee = calcRental(rule, ...)
```

### 6.2 产品组合示例

| 产品名 | service_mode | pricing_basis | 说明 |
|---|---|---|---|
| 自驾日租 | SELF_DRIVE | HYBRID | 200 元/天含 200km，超 1.5 元/km |
| 自驾月租 | SELF_DRIVE | TIME | 4500 元/月，不限里程或另议 |
| 商务包车（按天） | WITH_DRIVER | TIME | 800 元/天含司机 8h、含 300km |
| 商务包车（按里程） | WITH_DRIVER | MILEAGE | 3.5 元/km，最低消费 300 元 |
| 车队自驾批量 | SELF_DRIVE | TIME + qty_discount | 10 台商务车协议价 |

## 7. 附加费与叠加顺序

### 7.1 常见附加费（`surcharge_fee` / `order_fee_detail`）

| fee_type | 名称 | 触发条件 |
|---|---|---|
| `CROSS_STORE` | 异店还车 | `pickup_store_id != return_store_id` |
| `NIGHT_PICKUP` | 夜间取车 | 取车时段 ∈ 配置夜间窗 |
| `ONE_WAY` | 异地还车 | 跨城市 |
| `DELIVERY` | 送车上门 | 上门地址服务 |
| `FUEL` | 油费补差 | 还车油格低于取车 |
| `CLEANING` | 清洁费 | 验收判定 |
| `OVERTIME` | 超时租金 | 还车晚于约定 |
| `MILEAGE_OVERAGE` | 超公里 | HYBRID 模式结算 |
| `DEPOSIT` | 押金 | 冻结，结算后退还（非收入） |

### 7.2 叠加顺序（建议固定，避免争议）

1. 匹配 **price_rule** 得基准租金（时间/里程/混合）
2. 应用 **时段系数**（周末、节假日）
3. 应用 **门店/城市系数**
4. 应用 **车辆数量折扣**
5. 应用 **B/G 协议价**（若命中合同价表，可覆盖 1~4）
6. 计算 **司机费**（仅 `WITH_DRIVER`）
7. 累加 **附加费**
8. 应用 **优惠券**（若有，最后一层，不作用于押金）

```
total_fee = rental_fee + chauffeur_fee + surcharge_fee - coupon_discount
```

## 8. 价格规则配置（运营后台）

扩展 FR-OPS-001，建议规则表逻辑结构：

### 8.1 `price_rule` 主表字段（建议）

| 字段 | 类型 | 说明 |
|---|---|---|
| `rule_code` | varchar | 唯一编码 |
| `rule_name` | varchar | 展示名 |
| `pricing_basis` | enum | TIME / MILEAGE / HYBRID |
| `time_unit` | enum | HOUR / DAY / WEEK / MONTH |
| `base_price` | numeric | 单位时间或单位里程基价 |
| `included_km` | int | 混合模式含公里（每单位时间或每单） |
| `overage_km_rate` | numeric | 超公里单价 |
| `vehicle_type_id` | uuid | 可空=全车型 |
| `service_mode` | enum | SELF_DRIVE / WITH_DRIVER / ANY |
| `store_id` | uuid | 可空=全门店 |
| `account_type` | enum | C / B / G / ANY |
| `min_qty` / `max_qty` | int | 车辆数阶梯 |
| `qty_discount_rate` | numeric | 批量折扣 |
| `weekend_rate` | numeric | 周末系数，默认 1.0 |
| `holiday_rate` | numeric | 节假日系数 |
| `effective_from` / `effective_to` | date | 生效期 |
| `priority` | int | 多规则命中时取优先级最高 |

### 8.2 规则命中优先级（高 → 低）

1. B/G **合同价表**（`contract_id` + 车型 + 服务方式）
2. 门店 + 车型 + 服务方式 + 数量阶梯
3. 城市 + 车型 + 服务方式
4. 平台默认价

## 9. 估价与结算流程

### 9.1 下单估价（Quote）

```pseudo
FUNCTION quoteOrder(draft):
  VALIDATE draft.pickup_time < draft.return_time
  VALIDATE draft.vehicle_qty >= 1
  VALIDATE draft.service_mode IN [SELF_DRIVE, WITH_DRIVER]

  lines = []
  FOR each line IN draft.order_lines:   // 每车型+数量
    rule = matchPriceRule(
      vehicle_type_id = line.vehicle_type_id,
      store_id = draft.pickup_store_id,
      service_mode = draft.service_mode,
      account_type = draft.account_type,
      qty = line.qty,
      pickup_time = draft.pickup_time,
      return_time = draft.return_time
    )
    duration = calcBillingDuration(rule.time_unit, draft.pickup_time, draft.return_time)
    rental = calcRentalByBasis(rule, duration, line.estimated_km)
    chauffeur = IF draft.service_mode == WITH_DRIVER
                  THEN calcChauffeur(rule, duration, line.estimated_km)
                  ELSE 0
    surcharge = calcSurcharges(draft, rule)
    lines.append({ rental, chauffeur, surcharge, rule_snapshot: rule })

  subtotal = sum(lines)
  discount = applyQtyDiscount(subtotal, draft.total_vehicle_qty)
  coupon = applyCoupon(draft.coupon_id, subtotal - discount)

  RETURN {
    rental_fee_est, chauffeur_fee_est, surcharge_fee_est,
    total_fee_est, quote_lines: lines, expires_at: now() + 15min
  }
```

### 9.2 还车结算（Settlement）

与 [需求评审与设计完善](./租车平台需求评审与设计完善.md) §6.3 对齐，扩展如下：

```pseudo
FUNCTION settleReturn(orderId, returnContext):
  order = getOrder(orderId)
  rule = loadRuleSnapshot(order)   // 下单时 rule_snapshot，防调价纠纷

  actual_duration = calcBillingDuration(rule.time_unit, order.pickup_time, returnContext.actual_return_time)
  actual_km = returnContext.return_mileage_km - returnContext.pickup_mileage_km

  rental_fee = calcRentalByBasis(rule, actual_duration, actual_km)
  overtime_fee = calcOvertime(rule, order.return_time, returnContext.actual_return_time)
  mileage_fee = calcMileageOverage(rule, actual_km)
  chauffeur_fee = IF order.service_mode == WITH_DRIVER
                    THEN calcChauffeurActual(rule, actual_duration, actual_km)
                    ELSE 0

  fees = [rental_fee, overtime_fee, mileage_fee, chauffeur_fee,
          crossStoreFee(order), fuelFee(returnContext), damageFee(returnContext),
          incidentFees(order)]   // 事故费见 FR-ORD-010

  saveOrderFeeDetails(orderId, fees)   // 每项写入 order_fee_detail + rule_snapshot
  total = sum(fees) - coupons
  balance = total - order.paid_amount
  ...
```

### 9.3 纯按里程 vs 纯按时间 取高（可选规则）

部分包车合同约定「按天或按公里取较高者」：

```
IF rule.settlement_policy == MAX_TIME_OR_MILEAGE:
  total_rental = max(calcTimeAmount(...), calcMileageAmount(...))
```

需在 `price_rule` 增加 `settlement_policy` 字段，默认 `STANDARD`（混合模式为时间+超公里，非取高）。

## 10. 业务规则（定价专用）

| 编号 | 规则 |
|---|---|
| BR-PRC-001 | 下单估价结果 15 分钟内有效；超时重新报价 |
| BR-PRC-002 | 订单创建须持久化 `price_rule` 快照（`order_fee_detail.rule_snapshot` 或 `orders.pricing_snapshot`） |
| BR-PRC-003 | 还车结算以**快照规则**为准；运营调价仅影响新单 |
| BR-PRC-004 | `HYBRID` 模式：含公里数按「计费天数 × 每日含公里」与「整单含公里」二选一，须在规则中明示 |
| BR-PRC-005 | `MILEAGE` 模式：预估里程仅用于下单展示；结算以实际里程为准，差额进入尾款/退款 |
| BR-PRC-006 | `vehicle_qty > 1` 时，每台车须独立占用 `vehicle_availability`（BR-002 扩展） |
| BR-PRC-007 | `WITH_DRIVER` 未分配司机不得确认订单（BR-016） |
| BR-PRC-008 | `SELF_DRIVE` 订单 `chauffeur_fee` 必须为 0（BR-017） |
| BR-PRC-009 | 批量折扣与优惠券不可叠加时，以运营配置 `stack_policy` 为准并前台提示 |
| BR-PRC-010 | 事故**暂停计费**期间，按时间模式不计租金；按里程模式暂停累计（与 FR-ORD-010 联动） |

## 13. 验收要点

- [ ] 经济型自驾日租（HYBRID）：租 2 天、含 400km、实际 500km，超 100km 按单价计费正确
- [ ] 商务车 `WITH_DRIVER` 按天：司机费 + 租金拆分与展示符合规则
- [ ] 5 台同车型批量：数量折扣生效且 5 台库存均占用
- [ ] 协议价覆盖：B 端客户命中合同价，不与默认价混用
- [ ] 下单后改价：旧单结算仍用快照；新单用新规则
- [ ] 超时还车：产生 `OVERTIME` 明细且可开票金额与账单一致
