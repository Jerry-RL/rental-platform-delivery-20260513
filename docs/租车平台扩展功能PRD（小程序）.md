# 租车平台扩展功能PRD（小程序）

版本：v1.0  
日期：2026-05-18  
关联文档：`租车平台需求规格说明书.md`、`租车平台需求补充说明书（违章+GPS+地图）.md`

## 1. 产品目标

围绕车队管理与运营效率，新增“批量违章、GPS定位、到期提醒、地图能力”四项高价值功能，形成可演示、可收费、可持续扩展的小程序解决方案。

## 2. 用户与痛点

> 全量痛点与平台应对见 [租车平台业务背景与客户痛点说明.md](./租车平台业务背景与客户痛点说明.md)

- 车队管理员：手工查违章效率低、漏查多（对应 P-VIOLATION）
- 运营人员：车辆位置不透明、调度效率低；租期事故处置分散（见 [需求补充（事故+认证）](./租车平台需求补充说明书（事故处理+用户认证细化）.md)）
- 财务人员：第三方调用成本不可见；对公打款与账单难对齐（P-FINANCE）
- 管理层：担心地图商用授权成本过高；缺乏月/季/年营收与成本看板（P-OPS）

## 3. 功能方案

### 3.1 批量违章查询

**用户流程**

1. 选择车辆范围  
2. 发起批量查询  
3. 查看任务状态与结果  
4. 导出异常车辆清单  

**关键约束**

- 月度配额默认2次（可配置）
- 超额后按策略执行（拒绝/审批/付费）

### 3.2 GPS定位与轨迹

**用户流程**

1. 进入车辆详情  
2. 查看实时位置  
3. 选择时间范围查看轨迹  

**关键约束**

- 依赖厂商API可用性
- 轨迹数据保留周期可配置

### 3.3 到期提醒

**用户流程**

1. 配置提醒规则  
2. 系统定时扫描到期车辆  
3. 触发提醒并记录发送状态  

### 3.4 地图能力与授权控制

**用户流程**

1. 小程序输入起点位置  
2. 选择地图接入策略  
3. 根据授权状态动态启停高风险能力  

## 4. 核心指标（KPI）

- 违章查询人工处理时间下降 >= 60%
- 车辆实时定位覆盖率 >= 95%
- 到期提醒漏提醒率 <= 1%
- 第三方调用成本统计准确率 = 100%

## 5. 页面清单（小程序+后台）

- 小程序：车辆列表、车辆详情（定位/轨迹）、起点输入
- 后台：批量违章任务页、配额配置页、成本统计页、提醒规则页

## 6. 数据埋点建议

- 批量任务创建次数
- 单次任务车辆量
- 任务成功率/失败率
- 成本消耗趋势（日/周/月）
- 地图能力调用次数

## 7. 风险与应对

- 接口稳定性风险：重试 + 熔断 + 降级
- 成本失控风险：配额 + 审批 + 账单核对
- 合规风险：地图授权状态门禁 + 变更留痕

## 8. 版本计划

- V1：批量违章 + 配额成本 + 到期提醒
- V1.1：GPS实时定位 + 历史轨迹
- V1.2：地图授权策略 + 管理优化
