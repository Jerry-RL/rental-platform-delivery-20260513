# 租车平台验收标准与交付清单（扩展功能）

版本：v1.0  
日期：2026-05-18

## 1. 验收范围

本文件用于验收以下扩展能力：

- 批量违章查询
- 违章配额与成本控制
- GPS实时定位与轨迹
- 保险/年审到期提醒
- 地图策略与授权控制

## 2. 功能验收标准

### 2.1 批量违章查询

- [ ] 可批量提交车辆查询任务
- [ ] 任务状态可追踪（待处理/处理中/成功/部分成功/失败）
- [ ] 支持按车辆查看查询结果明细
- [ ] 失败任务支持重试并保留日志

### 2.2 配额与成本控制

- [ ] 支持每月查询次数限制（默认2次）
- [ ] 支持后台调整配额与超额策略
- [ ] 每次任务可查看车辆数、单价、总成本
- [ ] 月度成本报表与调用日志可对账

### 2.3 GPS与地图

- [ ] 支持车辆实时定位查询
- [ ] 支持历史轨迹按时间范围回放
- [ ] 地图页面可完成起点输入与定位选点
- [ ] 授权未确认时，高风险地图能力不可启用

### 2.4 到期提醒

- [ ] 支持保险到期提醒
- [ ] 支持年审到期提醒
- [ ] 提醒规则可配置且可追溯

## 3. 非功能验收标准

- [ ] 批量违章任务创建接口 P95 < 300ms
- [ ] 第三方接口失败具备重试与熔断机制
- [ ] 第三方调用日志完整（request_id、provider、status、cost）
- [ ] 关键操作具备审计日志（谁在何时进行了什么配置）

## 4. 联调验收用例（最小集）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| TC-EXT-001 | 提交30辆车批量违章查询 | 任务成功创建并逐车回填结果 |
| TC-EXT-002 | 当月超过配额再发起查询 | 返回超额错误或进入审批流程 |
| TC-EXT-003 | 模拟违章接口超时 | 系统自动重试并记录失败日志 |
| TC-EXT-004 | 查询车辆实时定位 | 返回最新经纬度与时间戳 |
| TC-EXT-005 | 查询车辆近7天轨迹 | 返回轨迹点并可视化展示 |
| TC-EXT-006 | 地图授权状态设置为未确认 | 高风险能力入口不可用 |
