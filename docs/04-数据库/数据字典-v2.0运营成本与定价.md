## 1. 运营成本域（V9）

### 1.1 `cost_sub_type_dict`

成本子类字典，主键 `(cost_category, cost_sub_type)`。预置 40+ 子类（人力/车辆/公司运营/第三方/订单关联）。

### 1.2 `operating_cost_entry`

| 字段 | 类型 | 说明 |
|---|---|---|
| entry_no | varchar(40) | 单据号，唯一 |
| cost_category | varchar(30) | LABOR / VEHICLE / COMPANY_OPEX / THIRD_PARTY / ORDER_LINKED |
| cost_sub_type | varchar(40) | 关联字典 |
| amount | numeric(12,2) | 含税金额 |
| accrual_month | varchar(7) | YYYY-MM |
| vehicle_id | uuid | 单车成本归集 |
| driver_id | uuid | 司机成本 |
| order_id | uuid | 订单关联成本 |
| source | varchar(20) | MANUAL / IMPORT / AUTO_API / WORK_ORDER / INCIDENT / ALLOCATION |
| source_ref_id | uuid | 幂等键组成部分 |
| integration_ledger_id | uuid | 关联第三方台账 |
| status | varchar(20) | DRAFT / CONFIRMED / VOID |

唯一索引：`(source, source_ref_id, cost_sub_type)` 且 `status <> VOID`。

### 1.3 `integration_cost_ledger`

| 字段 | 类型 | 说明 |
|---|---|---|
| provider | varchar(30) | 如 SHUMAI |
| request_id | varchar(64) | 幂等 |
| unit_cost | numeric(10,4) | 默认 0.06（违章） |
| total_cost | numeric(12,4) | quantity × unit_cost |
| operating_cost_entry_id | uuid | 同步运营台账后回填 |

### 1.4 `driver`

司机档案：`driver_no`、`full_name`、`employment_status`（ACTIVE/ON_LEAVE/RESIGNED）。`orders.driver_id` 可 FK 关联。

### 1.5 `vehicle_maintenance_work_order`

维保工单：`work_type` = MAINTENANCE_ROUTINE | REPAIR；完成后关联 `operating_cost_entry_id`。

### 1.6 `vehicle_insurance_policy`

保险/年审：`policy_type` = INSURANCE_COMPULSORY | INSURANCE_COMMERCIAL | ANNUAL_INSPECTION；`amortize_monthly` 控制按月摊销入账。

### 1.7 `operating_cost_budget` / `cost_allocation_rule`

月度预算与公司费用分摊规则（P2）。

## 2. 订单定价域（V10）

### 2.1 `price_rule`

| 字段 | 说明 |
|---|---|
| pricing_basis | TIME / MILEAGE / HYBRID |
| time_unit | HOUR / DAY / WEEK / MONTH |
| base_price | 单位时间或里程基价 |
| included_km | 混合模式含公里 |
| overage_km_rate | 超公里单价 |
| service_mode | SELF_DRIVE / WITH_DRIVER / ANY |
| min_qty / max_qty / qty_discount_rate | 批量折扣 |
| settlement_policy | STANDARD / MAX_TIME_OR_MILEAGE |
| priority | 规则命中优先级 |

### 2.2 `orders` 新增列

| 字段 | 说明 |
|---|---|
| pricing_basis | 计费模式快照 |
| price_rule_id | 命中规则 |
| pricing_snapshot | 规则 JSON 快照 |
| estimated_km / included_km / actual_km | 里程 |
| pickup_mileage_km / return_mileage_km | 结算里程 |
| vehicle_qty | 车辆台数 |

### 2.3 `order_line`

多车型/多台：`line_no`、`vehicle_type_id`、`qty`、`vehicle_ids[]`、预估费用、`rule_snapshot`。
