# 数据字典 — v1.9 扩展（事故 / 认证 / 银行勾稽）

版本：1.0  
日期：2026-06-01  
迁移脚本：`Migrations/Flyway/V5__v1_9_incident_auth_bank.sql`

---

## 1. 用户域（user-service）

### 1.1 `users` 新增字段

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| realname_status | varchar(20) | NOT_SUBMITTED | NOT_SUBMITTED / PENDING / APPROVED / REJECTED |
| realname_reject_reason | varchar(255) | — | 实名驳回原因 |
| blacklist_flag | boolean | false | 黑名单标记 |

### 1.2 `user_license` 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| license_class | varchar(10) | 准驾车型，如 C1 |
| verify_status | varchar(20) | 驾照审核状态 |
| reject_reason | varchar(255) | 驳回原因 |

### 1.3 新表

| 表名 | 用途 | 关键关联 |
|---|---|---|
| user_oauth_binding | 微信/支付宝绑定 | user_id |
| user_realname_verify | 实名审核流水 | user_id |
| user_eligibility_snapshot | 下单资格快照 | user_id, org_id |
| org_credit_line | 组织授信额度 | org_id (1:1) |
| org_invoice_title | 企业开票抬头 | org_id |

### 1.4 `org_account` 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| qualification_status | varchar(20) | DRAFT / UNDER_REVIEW / ACTIVE / SUSPENDED / CLOSED |
| legal_person_name | varchar(64) | 法人姓名 |
| bank_account_enc | text | 对公账户（加密） |
| business_license_url | text | 执照附件 URL |

## 2. 订单域（order-service）

### 2.1 `orders` 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| booker_user_id | uuid | 下单人（代订场景） |
| actual_driver_user_id | uuid | 实际驾驶人 |
| eligibility_snapshot_id | uuid | 资格校验快照 ID |
| incident_pending | boolean | 是否存在未结案事故 |
| credit_snapshot | jsonb | POSTPAID 授信快照 |

### 2.2 事故相关表

| 表名 | 用途 |
|---|---|
| order_incident | 租期事故主表 |
| order_incident_attachment | 现场照片/认定书附件 |
| order_incident_status_log | 状态变更审计 |
| order_incident_fee | 事故费用明细 |

**`order_incident.status`**：`REPORTED` → `UNDER_REVIEW` → `INSURANCE_PROCESSING` → `RESOLVED` / `CLOSED`

**`order_incident.incident_type`**：`COLLISION` | `SCRATCH` | `THEFT` | `OTHER`

---

## 3. 车辆域（vehicle-service）

### 3.1 `vehicle.status_code`

| 值 | 说明 |
|---|---|
| AVAILABLE | 可租 |
| RENTED | 已租出 |
| MAINTENANCE | 维保中 |
| ACCIDENT_HOLD | 事故停运（不可新占库存） |
| SCRAPPED | 报废 |

> `status`（smallint）保留兼容；新逻辑以 `status_code` 为准。

---

## 4. 财务域（payment-finance-service）

### 4.1 `finance_bills` 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| payment_reference_code | varchar(64) unique | 对公回款识别码 |

### 4.2 银行流水表

| 表名 | 用途 |
|---|---|
| bank_statement_import | 导入批次 |
| bank_statement_line | 单条银行流水 |
| bank_statement_match | 流水与账单匹配记录 |

**`bank_statement_line.match_status`**：`UNMATCHED` | `AUTO_MATCHED` | `MANUAL_MATCHED` | `IGNORED`

**`bank_statement_match.match_rule`**：`REFERENCE_CODE` | `BILL_NO` | `AMOUNT_DATE` | `MANUAL`

### 4.3 `invoices.invoice_title_id`

关联 `org_invoice_title.id`（B/G 开票）。
